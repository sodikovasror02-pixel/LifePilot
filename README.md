## Лаҳза (`lahza/`)
Барномаи иҷтимоии суратҳо (PWA): пост бо филтрҳо, сторис (24 соат), лайк (ду бор зер кардан), шарҳ, захира, ҷустуҷӯ бо #ҳештегҳо, профил, реҷаи торик ва нусхаи эҳтиётӣ.
Ҳама маълумот дар браузери худи дастгоҳ (IndexedDB) нигоҳ дошта мешавад. Барои насб `lahza/`-ро дар сайти HTTPS ҷойгир кунед ва дар Chrome «Насб кардани барнома»-ро интихоб кунед.
